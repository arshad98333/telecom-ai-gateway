# The brief

The source specifications this system was built to satisfy, unedited. They are here so
a reader can check the code against what was actually asked for, rather than against a
summary of it.

| File | What it specifies |
|---|---|
| `sop-voice-support-system.json` | The operating rules: security controls, approval rules, testing standards, failure handling, release control |
| `project-1-mcp-tools.json` | The MCP tool package — the tools, their owners, the week-one scope |
| `project-2-knowledge-system.json` | The knowledge system with search and relationships |
| `project-3-conversation-design.json` | Conversation start, consent, and the core design decisions |
| `release-and-completion.json` | Deployment and rollback ownership per project |

`docs/SYSTEM-DESIGN.md` is how these were answered. `docs/decisions/` is why each
non-obvious choice was made.
