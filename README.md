# telecom-mcp-tools

Security-enforcing MCP tool server for the telecom AI voice support agent.
See `docs/PLAN.md` for the build plan. Full README lands with the first working slice.

## Requirements

- Python 3.12 (pinned in `.python-version`)
- [uv](https://docs.astral.sh/uv/) 0.12 or newer

## Install and test

```
make install
make test
```
